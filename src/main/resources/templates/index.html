Gerar trafego

Cada botao executa uma requisicao HTTP real no backend. Os status resultantes alimentam http_server_requests_seconds no Prometheus e os paineis 2xx / 4xx / 5xx do Grafana.

O backend chama os proprios endpoints com uma mistura de 2xx, 4xx e 5xx (limite de 200 por rajada), garantindo series reais nos dashboards.

Gerar logs

Os eventos sao emitidos pelo Logback no backend e enviados ao Graylog pelo appender GELF, com level_name, application e correlation_id pesquisaveis.

Envio ao Graylog: gere um log para verificar

Como pesquisar no Graylog

Em Search, use application:spring-devops-observability e filtre por nivel com level_name:ERROR.
